# Asset provenance notes (AUD-56 supplement)

Supporting notes for `assets/asset-manifest.csv`, which this branch populated
from zero records to 42 rows. Nothing here overrides
[asset policy](../10-licensing-and-assets.md); this file records how each row
was evidenced, decisions about column semantics, and the resolution of the
former unknown audio set.

## Scope and method

Rows were derived from what the content pipeline actually consumes:

- `QinglanMeshImport.cpp` — five Quaternius packs (raw root
  `assets-raw/quaternius/extracted`) imported to `/Game/Qinglan/{Characters,Weapons,Environments}`.
- `QinglanContentBootstrap.cpp` — 20 PolyHaven surface sets imported to
  `/Game/Qinglan/Materials` (MIC) + `/Game/Qinglan/Textures` (import target).
- `assets-raw/polyhaven/hdris` — 8 HDRIs acquired by the fetch script but not
  wired to any commandlet yet; recorded anyway so the acquisition is tracked.
- `QinglanAudioBootstrap.cpp` — 8 project-original WAVs (4 music loops,
  4 SFX) generated 2026-10-19 under `assets-raw/audio/original/` (see
  [Original audio replacement](#resolved-original-audio-replacement-2026-10-19)).

## Column semantics decisions

- The original 13-column header from `docs/10-licensing-and-assets.md` was kept
  unchanged; no extra columns were needed.
- `acquired_version` carries fetch date plus archive vintage where the pack's
  internal timestamps indicate one (the packs are not versioned upstream).
- `attribution` is `no` for CC0 rows (not required), followed by a courtesy
  credit string the release credits screen can lift verbatim.
- `public_path` is the committed `/Game/...` location of the derived uasset.
  Raw third-party sources stay outside the repository in `assets-raw/` per the
  policy on public Git distribution; CC0 would permit source redistribution,
  but that is a choice, not an obligation.
- No row now uses `pending`: the eight audio rows that carried it were
  resolved by the project-original replacement on 2026-10-19.

## License conclusions

- **Quaternius (5 packs):** CC0 1.0 Universal. Free use, cooked distribution,
  and source redistribution are all permitted; attribution not required.
  Two packs prove this locally via `License.txt`; the other three are proven
  by their OpenGameArt pages. TODO: mirror those page licenses into
  `assets-raw` as local text files so the evidence survives link rot.
- **PolyHaven (21 texture sets, 8 HDRIs):** CC0. Same conclusions as above.
  One texture set (`cobblestone_04`) is acquired but unused; 8 HDRIs are
  acquired but not yet imported. Neither blocks anything.
- **Audio (8 files):** project original, all rights reserved by the project.
  No third-party attribution or redistribution obligation applies. The
  untraceable predecessors were replaced on 2026-10-19 — see below.

## Resolved: original audio replacement (2026-10-19)

**project-original material** generated by
`assets-raw/audio/original/generate_original_audio.py`. The script uses only
the Python standard library (`wave`, `struct`, `math`, `random`): layered
sine/saw partials, noise bursts, exponential envelopes, and simple one-pole
filtering. No third-party sample, recording, instrument library, or model was
used, so the output is owned by the project (all rights reserved) with no
attribution or redistribution obligation.

Music loops use integer-cycle tonal layers and circularly wrapped event tails,
so the loop boundary is continuous. `QinglanAudioBootstrap.cpp` now imports
`original/music/...` and `original/sfx/...`; the base names are unchanged, so
the target assets remain `/Game/Qinglan/Audio/{Music,SFX}/SW_<base>` and the
runtime paths in `QinglanAudioSubsystem.cpp` need no change.

The previous files under `assets-raw/audio/music/` and `assets-raw/audio/sfx/`
(including the two `.ogg` variants) are **retained on disk as audit evidence
but are no longer imported or shipped**. The committed `SW_*` uassets still
contain the pre-replacement audio until the next regeneration; the bootstrap
now compares the stored `AssetImportData` source path and re-imports when it
differs, instead of reusing a stale import. After regeneration, remaining
acceptance is human listening QA (loop seams, relative mix, SFX transients);
no provenance gate remains.
