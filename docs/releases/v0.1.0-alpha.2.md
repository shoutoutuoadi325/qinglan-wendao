# Qinglan: Path of Ascension — v0.1.0-alpha.2 (macOS, Apple Silicon)

**This is an early, unsigned alpha build.** It is not signed with an Apple
Developer ID and it is not notarized. macOS will show a security warning on
first launch; follow the steps below.

This build supersedes `v0.1.0-alpha.1`. It is compiled from the repaired
source tag `v0.1.0-alpha.2` and passes the full 2026-10-22 acceptance run.

## Download

- `Qinglan-0.1.0-alpha.2-macOS-arm64.dmg`
- `SHA256SUMS`

Only download these files from this GitHub Release. Do not use mirrors.

## Requirements

- Apple Silicon Mac (M1 or newer). Intel Macs are not supported.
- macOS 14.0 or newer.
- About 2 GB of free disk space.
- Keyboard and mouse. Gamepad support is not verified yet.

## Install (English)

1. Download the `.dmg` and `SHA256SUMS` into the same folder.
2. Verify the checksum: `shasum -a 256 -c SHA256SUMS`.
3. Open the `.dmg` and drag **Qinglan - Path of Ascension** into
   **Applications**.
4. Open the app once and dismiss the warning.
5. Open **System Settings > Privacy & Security**, find Qinglan in the
   **Security** section, and click **Open Anyway**.
6. Authenticate and confirm **Open**, then open the app again.

If macOS says the app is damaged, remove the quarantine flag for this app only:

```sh
xattr -dr com.apple.quarantine "/Applications/Qinglan - Path of Ascension.app"
```

Only do this for the official download after verifying the checksum. Never
run `sudo spctl --master-disable` and never disable Gatekeeper globally.

A bilingual English/Simplified Chinese install guide is included as
`INSTALL.txt` inside the DMG.

## Why is this unsigned?

Apple Developer Program membership costs 99 USD per year. The owner has chosen
not to enroll for this alpha, so the build is ad-hoc signed only. Apple
Gatekeeper therefore blocks the first launch. A Developer ID signed and
notarized build remains the goal for a later release; this alpha is an
explicit, clearly labeled preview.

## What is in this build

Recorded by the 2026-10-22 acceptance run after repairing the corrupted
character-source batch:

- Editor build green; named automation suite **90/90**.
- Main campaign journeys **30/30 scenes** and side campaign **24/24 stages**
  in automation, with 0 blocked.
- Mac arm64 Shipping package built with UAT `BuildCookRun` rc=0.
- The re-signed DMG app boots, renders, writes a frame, and exits cleanly.

This is still **not** a verified complete interactive playthrough. Realm,
trial, ending, defeat, retreat, retry, gamepad, and target-hardware
performance routes remain open.

## Known limitations

- Early alpha: expect bugs, placeholder art, and unfinished flows.
- The full campaign has not been interactively verified end to end.
- No auto-update. Replace the app manually with a newer DMG.
- Save compatibility across versions is not guaranteed yet.
- Gamepad support is not verified.
- Windows builds are not part of this release.

## Save data and uninstall

Saves live inside the app's sandbox container:

```text
~/Library/Containers/io.github.shoutoutuoadi325.qinglan/Data/
```

To uninstall, quit the game, delete the app, and optionally delete that
container. Back up the container before replacing the app with a newer build.
