## Installation & Running Instructions

### Windows (Direct Download)
1. Download `Qinglan-0.1.1-Windows-x64.zip` and verify its SHA-256 checksum.
2. Extract the archive to a local folder (e.g. `C:\Games\Qinglan`).
3. Run `Launch-Qinglan.bat` or `QinglanAscension\Binaries\Win64\QinglanAscension-Win64-Shipping.exe`.
4. *Prerequisites*: Windows 10/11 64-bit, DirectX 12 compatible GPU, and Microsoft Visual C++ 2015-2022 Redistributable (x64).

### macOS (Apple Silicon arm64)
1. Download `Qinglan-0.1.1-macOS-arm64.dmg` and `SHA256SUMS`.
2. Verify: `shasum -a 256 -c SHA256SUMS`.
3. Open the DMG and drag **Qinglan - Path of Ascension** to **Applications**.
4. Open the app once, dismiss the Gatekeeper prompt, navigate to **System Settings > Privacy & Security**, and click **Open Anyway**.
5. If macOS reports the app is damaged, clear quarantine for this application:
   ```sh
   xattr -dr com.apple.quarantine "/Applications/Qinglan - Path of Ascension.app"
   ```

A bilingual English/Simplified Chinese install guide is included as `INSTALL.txt` inside both download packages.
