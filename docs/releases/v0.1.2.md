# Qinglan: Path of Ascension — v0.1.2

This update repairs 65 related gameplay and usability defects across combat,
enemy AI, progression, save recovery, input routing, narrative, menus and VFX.
The full defect list and evidence are recorded in
[the gameplay audit](../dev/gameplay-bug-audit-2026-10-29.md).

Notable repairs include lost or stranded progress after save failures,
incorrect projectile and dodge timing, unreliable menu/gamepad input,
unreachable story continuations, overlapping HUD labels, white ground warnings
that obscure the hero, and invisible safe-sector markers.

The gameplay repair baseline passes 163/163 native regression registrations,
30/30 main scenes and 24/24 side stages on pinned Unreal Engine 5.8.3.
Current release builds target macOS Apple Silicon and Windows x64; the
Microsoft Store update uses package version 0.1.2.0 and the existing reserved
product identity. Release-build results and hashes are recorded separately
when their packages finish.

The macOS DMG uses ad hoc signing. It does not carry an Apple Developer ID
signature or notarization ticket; follow the included bilingual INSTALL.txt.
Windows Store artifacts are built with Microsoft GDK and its Submission
Validator, and include the encrypted MSIXVC, escrow key and validation records.

Physical-controller, Windows/DX12 gameplay, audio listening and a complete
manual playthrough remain outside the current gameplay repair evidence.
