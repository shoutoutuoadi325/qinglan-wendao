# Qinglan: Path of Ascension — v0.1.3

This macOS update adds a cultivator costume, original sanctuary architecture,
eroded rocks, bamboo clusters and stone lanterns across the four game maps.
Surface normal maps and revised lighting add detail while retaining the
existing character skeleton and gameplay animations.

Download Qinglan-0.1.3-macOS-arm64.dmg and SHA256SUMS. Verify the checksum,
open the disk image and drag **Qinglan - Path of Ascension** to **Applications**.
The disk image includes the bilingual installation guide, credits and license.
Requirements are Apple silicon and macOS 14 or newer.

The Mac packaging follows the same ad-hoc signing process as v0.1.2. Follow
the included INSTALL.txt for first-launch instructions.

Validation: 165 native regression checks passed (130 without warnings and 35
with warnings), with zero failed or skipped checks. The complete cooked app
was verified through real Metal game captures. Art remains stylized; face,
foliage and terrain composition still have visible limitations.

This package targets macOS Apple silicon. Windows artifacts are not included
in this packaging run.
