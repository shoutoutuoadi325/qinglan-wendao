# CH01 — Paths Left Open

Status: fully authored production script. Runtime text is authoritative in the paired locale files; this document defines staging, trigger order, and checkpoint behavior.

Chapter title key: `story.ch01.title`. Chapter synopsis key: `story.ch01.summary`.

## Scope and knowledge boundary

Downstream use is established by mandatory evidence. The three declining winters are facts, but their institutional cause remains unknown. The test outlet is a marked inspection fixture; it is not the concealed bypass. No additional villager model, rescue NPC, or new location is required.

## Global execution rules

- Dialogue is text-first and fully subtitled; voice acting is optional. Language switching resolves the same stable keys without restarting a scene.
- Scene commits occur in safe areas as ordered transactions. A scene’s completion flag is saved with its journal, objective, unlocks, and selected choice. A crash before commit resumes that scene; a crash afterward never reapplies its first-time rewards.
- Scene skipping applies the same mandatory journal/objective facts, then pauses at an unselected choice. A skip never supplies an attitude choice automatically. Ordinary dialogue can be reread from the journal; a reread never sets flags.
- An optional inspection is deliberately absent from the automatic dialogue sequence. Its key appears in `player_text_keys` and its activation is specified below. Optional inspection completion is not a main-story prerequisite.
- Choice response keys are spoken by Keeper Lan. Choice flags are mutually exclusive within a scene and record expressed priorities only. They do not remove any revelation, alter combat balance, or add a hidden virtue score.
- Completion expressions describe existing gameplay events, not new engine features. The runtime dispatcher binds those events to the exact flags below. Combat and economy rewards use the existing documents; this script never duplicates their payout.
- Player-profile names remain UI labels. Dialogue identifies the protagonist as Apprentice; recorded letters are visibly labeled and never respond to the present.
