# CH06: The Borrowed Sky

Survive the Core trial, end Shen’s service, and choose how the river will be kept.

Status: complete authored scene script. The authoritative text/choice specification is `data/story/main-late.json`. Every quoted player string below has an English and Simplified Chinese resource. Production direction is English. No placeholder dialogue or dynamic prose generation is required.

## Chapter implementation rules

- Narrative scene flags commit only on the documented completion condition, never merely on entering or opening a text panel. Dialogue response keys execute only when their corresponding choice is selected. All factual evidence is presented regardless of tone choices.
- Interact uses the existing rebindable action. Text is paged without a timer, supports manual advance and transcript review, and uses text-only delivery with existing portraits/props. No new voice pipeline is required.
- Save completed evidence and choice response before closing the interaction. Reload resumes at the first unread page; a fully completed interaction opens in reread mode and never reissues its flags or rewards. Combat reload starts from the established preparation checkpoint.
- Skip advances noninteractive staging and supplies the scene journal/summary. Required evidence summaries, live-consent acknowledgment, and final choice remain explicit interactions. Skip never chooses a reply, an ending, or confirmation.
- Dialogue never hides an active combat warning. Combat barks have subtitles and an ordered transcript, and repeated barks are rate-limited. Pausing, reading, and finishing optional tasks do not run a narrative deadline.
- The main quest journal keeps the original documents and each scene summary permanently, so recovered evidence remains accessible after the ending.

### Failure, resume, and access

The UI state sequence is Browse → Preview → Confirmation → Commit. Return/Cancel leaves every `ending_*` flag unset. At Commit, validate `mq_shen_released`, selected preview, explicit warning acknowledgment, and all selected choice prerequisites against the current saved state. Persist exactly one ending flag and `mq_ch06_complete` together. A missing prerequisite or failed save leaves the player in Confirmation with no partial ending. Closing/reopening a pending confirmation returns to Browse; it does not infer approval. After a successful commit, further choice calls are rejected as already completed and the selected ending card is readable from the journal.

The three individual readiness messages are selected from their ready/missing pairs using the named side flags. Disabled Shared remains inspectable through the card explanation but its preview-to-confirm transition is blocked. Return-to-hub preserves the release checkpoint; the shrine’s decision marker returns directly to this scene. Optional safe-state excursions cannot accidentally restart or undo the storm trial.
