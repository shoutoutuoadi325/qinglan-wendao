# 隐私政策

**Qinglan: Path of Ascension**  
发布者：Zhiqi Zhang  
生效日期：2026-10-25

[English](../../PRIVACY.md)

《Qinglan: Path of Ascension》是一款离线单人游戏，无需注册账号即可游玩。
游戏不包含广告、内购或网络行为分析，也不会自动向发布者上传您的存档或游戏日志。

游戏进度、设置、可选的存档名称及运行诊断日志保存在您的设备本地，用于存档读取、
保存个人偏好及排查问题。您可以在游戏内管理本地存档和设置。游戏不提供云同步服务。

如果您联系支持，我们会收到您主动发送的信息，例如电子邮箱地址、问题描述及附件。
我们使用这些信息回复您的请求并排查问题。请勿发送密码、支付信息、个人文件路径
或其他不必要的个人信息。GitHub 上的公开问题报告可被其他人阅读；如需私下联系，
请使用电子邮件。支持通信仅在处理请求或履行适用法律义务所需的期限内保留。

Microsoft Store、Windows、您的电子邮件服务商及 GitHub 分别适用其自身的隐私政策，
其数据处理与游戏的本地数据相互独立。

如有隐私问题，或希望就您已发送的支持信息提出请求，请联系
**zhiqizhangg@gmail.com**。一般游戏问题也可通过
[GitHub Issues](https://github.com/shoutoutuoadi325/qinglan-wendao/issues) 反馈。
本政策如有变更，将在此公布并更新生效日期。
