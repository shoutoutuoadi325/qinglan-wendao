# Windows Packaging Templates

The XML is an incomplete planning template. M0 must prove the selected Unreal Win64/GDK workflow, schema, dependencies, executable path, shell assets, and bilingual resource tags using the actual SDK and Partner Center product. Do not upload this template or claim validation based on XML parsing alone.

No Xbox services are included. Do not add `MSAAppId`, `TitleId`, or `ExtendedAttributeList` without a new integration decision. Real identity values and signing/package keys remain owner-controlled release configuration. See [the distribution guide](../../docs/09-distribution.md).
