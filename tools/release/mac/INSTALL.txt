Qinglan: Path of Ascension - macOS (Apple Silicon) alpha
=========================================================

Requirements
- Apple Silicon Mac (M1 or newer). Intel Macs are not supported.
- macOS 14.0 or newer.
- About 2 GB of free disk space.
- Keyboard and mouse. Gamepad support is not verified yet.

Install
1. Open the downloaded .dmg.
2. Drag "Qinglan - Path of Ascension" into the Applications folder.
3. Eject the disk image.

First launch (unsigned alpha)
This build is NOT signed with a Developer ID certificate and is NOT notarized
by Apple. macOS will block the first launch. Only the official GitHub release
is supported.

1. Open the app once and dismiss the warning.
2. Open System Settings > Privacy & Security.
3. In the Security section, click "Open Anyway" for Qinglan.
4. Authenticate and confirm "Open".
5. Open the app again.

If macOS says the app is damaged, remove the quarantine flag for this app only:
  xattr -dr com.apple.quarantine "/Applications/Qinglan - Path of Ascension.app"
Only do this after verifying SHA256SUMS. Never run "sudo spctl --master-disable"
and never disable Gatekeeper globally.

Verify the download
  shasum -a 256 -c SHA256SUMS
The SHA256SUMS file must be in the same folder as the .dmg.

Save data and uninstall
- Saves live inside the app's sandbox container:
  ~/Library/Containers/io.github.shoutoutuoadi325.qinglan/Data/
- To uninstall, quit the game, delete the app, and optionally delete that
  container.
- Back up the container before replacing the app with a newer build.

Known limitations
- Early alpha: the full campaign has not been interactively verified end to end.
- No auto-update; replace the app manually.
- Save compatibility across versions is not guaranteed yet.
- The build is unsigned. macOS may show a security warning on first launch.

简体中文
========
系统要求
- Apple Silicon（M1 或更新）Mac；不支持 Intel Mac。
- macOS 14.0 或更新。
- 约 2 GB 可用磁盘空间。
- 键盘和鼠标；手柄支持尚未验证。

安装
1. 打开下载的 DMG。
2. 把 “Qinglan - Path of Ascension” 拖进“应用程序”文件夹。
3. 推出磁盘映像。

首次启动（未签名 alpha）
此版本没有 Apple Developer ID 签名，也没有经过 Apple 公证，macOS 会拦截
首次启动。仅支持从官方 GitHub Release 下载。

1. 先双击一次 App，关闭警告。
2. 打开“系统设置 → 隐私与安全性”。
3. 在“安全性”区域找到 Qinglan，点击“仍要打开”。
4. 输入登录密码并确认“打开”。
5. 再次打开 App。

如果 macOS 提示“已损坏”，只对这个 App 移除隔离标记：
  xattr -dr com.apple.quarantine "/Applications/Qinglan - Path of Ascension.app"
请先用 SHA256SUMS 校验，再执行。不要运行
“sudo spctl --master-disable”，不要全局关闭 Gatekeeper。

校验下载
  shasum -a 256 -c SHA256SUMS
SHA256SUMS 必须和 DMG 放在同一个文件夹。

存档与卸载
- 存档位于沙盒容器：
  ~/Library/Containers/io.github.shoutoutuoadi325.qinglan/Data/
- 卸载：退出游戏，删除 App；如需要，再删除上述容器。
- 用新版本替换 App 前，请先备份该容器。

已知限制
- 早期 alpha：完整战役尚未经过端到端交互验证。
- 没有自动更新，需要手动替换 App。
- 跨版本存档兼容性暂不保证。
- 未签名版本，首次启动会出现安全提示。
